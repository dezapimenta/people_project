# GPM — Gestão de Projetos · People Tech

Plataforma interna de gestão de projetos. Protótipo de design em HTML + React (sem build, dados mockados).

## Rodar local
```bash
npx serve .
```
Abrir GPM.html no browser.

## Arquivos
- index.html — versão standalone (tudo inline, pronto pra Pages)
- GPM.html — entrypoint da versão modular
- gpm.css, *.jsx — código-fonte
- assets/ — tokens do DS Neon

## GitHub Pages
Settings → Pages → Source: main / root. Pages em repo privado exige Pro/Team/Enterprise.
